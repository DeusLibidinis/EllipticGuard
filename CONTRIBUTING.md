# Contributing

Propose small, reproducible improvements. Document device/firmware versions and actual sensor behavior. Avoid guessing handles and do not redistribute proprietary binaries. Open an issue first for new devices or changes to background service behavior. Keep sensor-control commands reversible and explicit.

For rootless automatic boot claims, supply a sequence showing: boot without opening the app, first unlock, foreground service present, independent proximity test, then several lock/unlock cycles.

No signing keys, IMEI/serial IDs, full system dumps with personal data, user messages or confidential materials should be committed.
